# Runbook

このドキュメントは、リポジトリ運用とトラブルシューティングのメモを記載します。

このリポジトリは現在、開発で利用する Tool の Markdown 一覧を主な成果物としています。コード実装から読み取れる詳細は重複して記載しません。

## 日常の更新

1. `README.md` の該当 Category に Tool を追加・更新する。
2. 利用を終了した Tool は削除せず、既存の取り消し線形式で記録する。
3. 用語や分類ルールに影響する場合は `CONTEXT.md` を更新する。
4. 長期的な選定判断が必要な場合は ADR を提案する。

## 検証

現時点では自動テスト、lint、型チェック、デプロイ手順は定義されていません。

- Markdown を目視確認し、見出しと箇条書きの構造が維持されていることを確認する。
- HTML 成果物を追加した場合は、ブラウザで表示とリンクを確認する。

## バックアップと復旧

Git の履歴と GitHub のリモートリポジトリを復旧元とします。意図しない変更は対象ファイルの Git 履歴を確認して復元してください。

## シークレットと設定

このリポジトリにシークレットを保存しないでください。外部サービスの認証情報を文書化する場合も、値そのものではなく安全な参照先のみを記載してください。
